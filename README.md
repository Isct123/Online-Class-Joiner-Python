# Online-Class-Joiner-Python

# Requirements
1. Python 3(This is purely coded in python)
2. Excel/Any software that can edit .xlsx files 
3. Pandas Library in python- You can do this by going to your terminal and writing 'pip install pandas' on windows and 'pip3 install pandas' on mac or you could download it <a href = "https://pandas.pydata.org/"><a/>.

# What it does
Ever since lockdown started, joining my online classes was quite a trouble. This is because I had to first download my timetable, then find out what class I have, then join that link, then type the password. I had to do this 3 times a day 6 days a week this monotonous process normally took me more than a minute, inevitably joining class late. This beautiful piece of code helps you join class almost effortlessly. 

# Features
1. Automatic mode (Recommended)- Joins your class instantly with just one click of a button (using the data provided in the excel sheet.
2. Manual mode- Joins the class that you want it to. Simply type in the class, and then it will join that.
3. Takes care of typos on your end
4. Opens up links on your default browser

# Installation and how to run
1. To download it, you can clone the repository or download the zip or click on <a href = "https://github.com/Isct123/Online-Class-Joiner-Python/archive/refs/heads/main.zip">this</a> link 
2. Unzip the file
3. Run the file called 'main.py'

# Instructions
First of all, you need to fill in data in the excel file. The Subject, Link, Time, Day columns are compulsary and the others are optional.
Once you're done filling in your excel file, you can either choose manual mode or automatic mode (explained above). 
BOOM!, That's all you need to do!
